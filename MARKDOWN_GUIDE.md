# Notion Mini Clone - Editor Markdown

Este clon de Notion ahora incluye soporte completo para **Markdown** en el editor de documentos.

## Características del Editor Markdown

### ✨ Funcionalidades Principales

- **Editor con pestañas**: Alterna entre modo edición y vista previa
- **Barra de herramientas**: Botones rápidos para formato común
- **Vista previa en tiempo real**: Renderizado instantáneo del markdown
- **Sintaxis highlighting**: Resaltado de código con highlight.js
- **Ayuda integrada**: Guía de sintaxis markdown disponible

### 📝 Sintaxis Markdown Soportada

#### Encabezados
```markdown
# Título Principal (H1)
## Subtítulo (H2)  
### Sección (H3)
```

#### Formato de Texto
```markdown
**Texto en negrita**
*Texto en cursiva*
`código inline`
~~texto tachado~~
```

#### Listas
```markdown
- Lista con viñetas
- Segundo elemento
  - Sub-elemento

1. Lista numerada
2. Segundo elemento
3. Tercer elemento
```

#### Enlaces e Imágenes
```markdown
[Enlace a Google](https://google.com)
![Texto alternativo](url-de-imagen.jpg)
```

#### Bloques de Código
```markdown
\`\`\`javascript
function saludo(nombre) {
  console.log(`¡Hola, ${nombre}!`);
}
\`\`\`
```

#### Citas
```markdown
> Esta es una cita
> Puede tener múltiples líneas
```

#### Tablas
```markdown
| Columna 1 | Columna 2 | Columna 3 |
|-----------|-----------|-----------|
| Fila 1    | Dato A    | Dato B    |
| Fila 2    | Dato C    | Dato D    |
```

#### Separadores
```markdown
---
```

### 🚀 Cómo Usar el Editor

1. **Crear un nuevo documento**: Haz clic en "+ Nuevo Documento"
2. **Escribir contenido**: Usa la pestaña "Editar" para escribir markdown
3. **Vista previa**: Cambia a la pestaña "Vista Previa" para ver el resultado
4. **Barra de herramientas**: Usa los botones para insertar formato rápidamente
5. **Ayuda**: Despliega la sección "Ayuda de Markdown" para referencia rápida
